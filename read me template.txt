## About

This Flask-based web application serves as my online portfolio. It includes a homepage, an "About" page, a "Projects" page to showcase my work, and a "Contact" page where users can submit messages. If an admin is logged in, they can view the messages submitted through the contact form, which are stored in the database.

Additionally, the website includes an audio player, allowing users to upload MP3, WAV, and OGG files to listen to music directly from the browser.

---

## Features

* **Homepage**: Introduction to who I am and what I do.
* **About Page**: Detailed information about my background, experience, and skills.
* **Projects Page**: A showcase of my work and technical projects.
* **Contact Me Page**: A form where users can send messages to me. Messages are stored in the database and can be viewed by an admin.
* **Admin View**: Logged-in admins can see submitted messages from the contact form.
* **Audio Player**: An embedded audio player to upload and listen to MP3, WAV, and OGG audio files.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/portfolio-flask-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio-flask-app
   ```

3. Create a virtual environment (optional but recommended):

   ```bash
   python3 -m venv venv
   ```

4. Activate the virtual environment:

   * **Windows**: `venv\Scripts\activate`
   * **Mac/Linux**: `source venv/bin/activate`

5. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Set up your environment variables (like Flask's secret key, database URL, etc.). You can use `.env` for storing sensitive data. For example:

   ```
   FLASK_APP=app.py
   FLASK_ENV=development
   SECRET_KEY=your_secret_key
   DATABASE_URL=your_database_url
   ```

## Usage

1. Start the Flask development server:

   ```bash
   flask run
   ```

2. Visit the application in your browser:

   ```
   http://127.0.0.1:5000
   ```

3. The app will be accessible locally. You can navigate through the homepage, about page, projects page, and contact form.

4. If you're logged in as an admin, you can access the admin panel to view submitted messages from the contact form.
